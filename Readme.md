## Creacion de la llave SSH
```bash
$ https://docs.github.com/es/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent
$ ssh-keygen -t ed25519 -C "your_email@example.com"
# Solo presionar la tecla ENTER
```


## Comandos de GIT
``` bash
# Para añadir los cambios
$ git add .  
# Para dar un mensaje a los cambios
$ git commit -m "[mensaje]"
# Para llevar los cambios a la nube
$ git push
# Para traer los cambios
$ git pull
# Para ver el estado de mi repositorio
$ git status
# Para unir ramas
$ git merge [rama_destino]
```
